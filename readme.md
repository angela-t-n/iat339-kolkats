# P01: Process
## Description

This project has you practicing a web development process which leads into P02: Company. You will develop a style guide for your company website. 

All code must be your own - no frameworks permitted for this project. 

Your style guide and company website should not be for an existing company that already has a website. 

Both P01 and P02 are group projects - 2 students per group. Please sign up your group on Canvas.
